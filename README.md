# 🚲 Bike Sharing Demand Forecasting – IBM Data Science Capstone (R)

This repository contains the capstone project for the **IBM Data Science with R Specialization**, focused on predicting hourly demand for bike rentals based on historical usage patterns and external variables.

## 📘 Project Overview

Urban bike-sharing systems generate large amounts of data related to hourly usage, weather, and user behavior. In this project, I used a dataset from a major city bike-sharing program to model and predict demand using machine learning techniques in R.

### 🎯 Objective

To develop a predictive model that accurately forecasts **bike rental demand** by hour, helping providers make data-driven operational decisions (e.g., rebalancing, staffing, maintenance).

---

## 📊 Key Deliverables

- Data cleaning and feature engineering from raw CSV files
- Exploratory Data Analysis (EDA) on weather, seasonality, time of day, and user types
- Linear regression and tree-based modeling using `caret` and `randomForest`
- Model evaluation using RMSE and cross-validation
- Final model selection based on performance and interpretability

---

## 🧰 Tools & Technologies

- **Language**: R  
- **Packages**: `ggplot2`, `dplyr`, `caret`, `randomForest`, `lubridate`, `corrplot`  
- **Notebook Format**: Final PDF Report  
- **Data Source**: UCI Machine Learning Repository - [Bike Sharing Dataset](https://archive.ics.uci.edu/ml/datasets/Bike+Sharing+Dataset)

---

## 📈 Key Insights

- **Hour of the day** and **weather conditions** are among the most influential predictors
- **Registered users** show strong weekday commute patterns, while **casual users** peak on weekends
- The final **random forest model** significantly outperformed linear regression, achieving lower RMSE on test data
